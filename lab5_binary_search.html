Divisão Inteira (//) e o Índice do Meio

Como encontrar exatamente o centro de qualquer fatia de uma lista ordenada.

Pendente (+50 XP)

➗ Por que usar // em vez de /?

Em Python, a divisão comum 5 / 2 gera 2.5 (float), que causa TypeError ao tentar acessar um índice de lista! Já a divisão inteira 5 // 2 arredonda para baixo e devolve o inteiro 2.

esq = 0
dir = 5
meio = (esq + dir) // 2  # (0 + 5) // 2 = 2 (índice central!)

🎯 Acessando o Elemento Central

Tendo o índice meio, basta acessar nums[meio] para inspecionar o valor que está exatamente no centro da janela atual.

nums = [10, 20, 30, 40, 50]
meio = (0 + 4) // 2      # meio = 2
valor = nums[meio]       # valor = 30

Dica: Calcule meio = (esq + dir) // 2 e na linha seguinte faça return [meio, nums[meio]].

Decidindo Para Qual Metade Ir

Como descartar metade da lista comparando o elemento do meio com o alvo.

Pendente (+50 XP)

🧭 A Bússola da Lista Ordenada

Como a lista está em ordem crescente, ao olhar para nums[meio] temos certeza absoluta de onde o alvo pode estar:

  • Se nums[meio] == alvo: Achamos! Retornamos meio.
  • Se nums[meio] < alvo: O meio é pequeno demais! O alvo só pode estar à DIREITA (esq = meio + 1).
  • Se nums[meio] > alvo: O meio é grande demais! O alvo só pode estar à ESQUERDA (dir = meio - 1).

⚡ Por que +1 e -1?

Como já testamos o índice meio e vimos que ele não é o alvo, nós o excluímos da próxima janela fazendo meio + 1 ou meio - 1. Sem isso, o loop poderia ficar preso para sempre!

Dica: Use if nums[meio] == alvo:, seguido de elif nums[meio] < alvo: e else:.
📖 Como resolver passo a passo:
  1. Calcule meio = (esq + dir) // 2.
  2. Compare nums[meio] com alvo usando if / elif / else.
  3. Lembre-se: se nums[meio] é menor que o alvo, precisamos de números maiores, logo vamos para a direita ("IR_DIREITA").

O Loop while esq <= dir e Contagem de Passos

Executando divisões sucessivas até encontrar o elemento ou esgotar a busca.

Pendente (+50 XP)

🔄 Quando a Busca Termina?

Enquanto esq <= dir, ainda existe pelo menos 1 elemento na janela para testar (quando esq == dir, a janela tem exatamente 1 elemento). Se os ponteiros se cruzarem (esq > dir), o elemento não existe na lista!

while esq <= dir:
    meio = (esq + dir) // 2
    if nums[meio] == alvo:
        return meio
    elif nums[meio] < alvo:
        esq = meio + 1
    else:
        dir = meio - 1
return -1  # Não encontrado

🚀 O Poder de O(log n)

Uma lista de 16 elementos leva no máximo 4 passos. Uma lista de 1.000.000 de elementos leva no máximo 20 passos!

🧩 Mini-Desafio 3: Contador de Divisões Binárias

Crie a função contar_passos_binarios(nums, alvo) que executa a busca binária contando quantas vezes o meio foi inspecionado até encontrar o alvo. Se encontrar, retorne o número de passos (passos). Se não existir na lista, retorne -1.

Dica: Inicie esq = 0, dir = len(nums) - 1 e passos = 0. Dentro do while esq <= dir:, some passos += 1 logo no início!
📖 Como resolver passo a passo:
  1. Inicialize esq = 0, dir = len(nums) - 1 e passos = 0.
  2. Em cada repetição do while esq <= dir:, incremente passos += 1 e calcule meio = (esq + dir) // 2.
  3. Se nums[meio] == alvo, retorne passos. Caso contrário, ajuste esq = meio + 1 ou dir = meio - 1.
  4. Fora do while, retorne -1.
