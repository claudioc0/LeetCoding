Módulo 2

Estruturas de Dados: Listas & Dicionários (Hash Maps)

A escolha da estrutura correta define a diferença entre um código lento e uma solução ótima aceita no LeetCode.

Pendente

📋 Lista (list)

Busca O(n)

Coleção ordenada indexada numericamente por inteiros (0, 1, 2...):

nums = [10, 20, 30]
nums.append(40)      # Adiciona ao fim
print(nums[0])       # Acesso por índice: 10
# Buscar 'if x in nums': percorre todos os itens O(n)

🗄️ Dicionário (dict)

Busca O(1) Instantânea

Mapeia chave: valor. A busca por chave usa tabela hash e leva tempo constante:

vistos = {}
vistos[2] = 0        # chave: 2, valor: índice 0
if 2 in vistos:      # Verificação instantânea O(1)!
    print(vistos[2]) # Retorna 0
💡 Por que Dicionários são o superpoder para o LeetCode?

Se você precisa verificar se um número já apareceu antes, buscar numa lista leva O(n) passos. Fazer isso para cada elemento resulta em O(n²). Guardando os números vistos em um Dicionário, cada consulta leva apenas O(1)!

Módulo 3

Loops Inteligentes: A Função enumerate()

Muitos iniciantes usam contadores manuais ou range(len(nums)). O modo idiomático em Python é enumerate().

Pendente

❌ Menos Idiomático em Python 

nums = [10, 20, 30]
# Usando range(len(...))
for i in range(len(nums)):
    valor = nums[i]
    print(i, valor)

✅ Pythonico com enumerate() 

nums = [10, 20, 30]
# Recebe simultaneamente (índice, valor)
for i, num in enumerate(nums):
    print(f"Posição {i}: {num}")

Módulo 4

O Padrão de Complementos (Hash Map)

Veja passo a passo como o raciocínio matemático se conecta com Dicionários para resolver o problema em tempo linear O(n).

Pendente
A Equação Chave:

Se queremos que A + B = Target, isso significa que para qualquer número A que estamos visitando, o número que precisamos encontrar é:

complemento = target - num

Em vez de fazer outro loop para procurar o complemento (o que levaria $O(n^2)$), basta verificar se ele já foi salvo no nosso dicionário vistos = {} em apenas $O(1)$!
