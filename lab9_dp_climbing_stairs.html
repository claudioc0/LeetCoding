🧱 Construindo do Degrau Base para o Topo

Na Programação Dinâmica (Bottom-Up Tabulation), criamos uma lista dp onde cada posição dp[i] guarda a resposta para o tamanho i, usando os dois valores anteriores já calculados:

dp = [0] * (n + 1)
dp[1] = 1
dp[2] = 2
for i in range(3, n + 1):
    dp[i] = dp[i - 1] + dp[i - 2]

✨ Multiplicação de Lista: [0] * (n + 1)

Em Python, [0] * 5 cria instantaneamente uma lista com cinco zeros [0, 0, 0, 0, 0] pronta para ser preenchida!

🧩 Mini-Desafio 1: Gerador de Tabela Fibonacci (DP)

Crie a função tabela_fibonacci(n) que cria uma lista começando com [0, 1] e adiciona os próximos elementos (onde cada novo elemento é a soma dos dois últimos) até o índice n incluso.

Dica: Inicie dp = [0, 1]. Use for i in range(2, n + 1): e faça dp.append(dp[i - 1] + dp[i - 2]). Retorne dp.
📖 Como resolver passo a passo:
  1. Comece com os casos base dp = [0, 1].
  2. Percorra for i in range(2, n + 1):.
  3. Adicione a soma dos dois anteriores com dp.append(dp[i - 1] + dp[i - 2]) e retorne dp.

Por Que Subir Escadas Segue Essa Recorrência?

Entendendo como chegamos ao degrau i dando passos de 1 ou 2 degraus.

Pendente (+50 XP)

🪜 De Onde Você Veio para Pisar no Degrau i?

Se você só pode subir 1 ou 2 degraus por vez, existem apenas duas maneiras de dar o último passo até o degrau i:

  • Estar no degrau i - 1 e subir +1 degrau.
  • Estar no degrau i - 2 e subir +2 degraus de uma vez.

Logo, o total de maneiras de chegar ao degrau i é exatamente a soma das maneiras de chegar ao degrau i - 1 mais as maneiras de chegar ao degrau i - 2!

🎯 Casos Base da Escada

Degrau 1: 1 maneira ([1]). Degrau 2: 2 maneiras ([1+1] ou [2]). Degrau 3: 2 + 1 = 3 maneiras!

📖 Como resolver passo a passo:
  1. Pela relação de recorrência da escada, some os dois estados anteriores: return formas_degrau_anterior + formas_dois_atras.

DP de Custo Mínimo em Degraus

Usando min() na transição de estados para escolher o caminho mais barato.

Pendente (+50 XP)

💰 Escolhendo o Menor Custo Acumulado

Em muitos problemas de Programação Dinâmica, em vez de somar caminhos, queremos o menor custo para chegar ao degrau i:

dp[i] = custos[i] + min(dp[i - 1], dp[i - 2])

Ou seja: pagamos o pedágio do degrau atual (custos[i]) somado ao mais barato entre vir de i - 1 ou vir de i - 2!

🧩 Mini-Desafio 3: Custo Mínimo até o Último Degrau

Crie a função custo_degraus(custos) onde dp[0] = custos[0], dp[1] = custos[1] e, para cada índice i de 2 até len(custos) - 1, dp[i] = custos[i] + min(dp[i - 1], dp[i - 2]). Retorne a lista dp completa.

Dica: Crie dp = [custos[0], custos[1]]. Faça for i in range(2, len(custos)): e adicione dp.append(custos[i] + min(dp[i - 1], dp[i - 2])).
📖 Como resolver passo a passo:
  1. Inicie a tabela com os dois primeiros custos: dp = [custos[0], custos[1]].
  2. Percorra for i in range(2, len(custos)):.
  3. Calcule o menor custo para pisar em i: dp.append(custos[i] + min(dp[i - 1], dp[i - 2])) e retorne dp.

Você está subindo uma escada que tem n degraus até o topo. A cada vez, você pode subir 1 ou 2 degraus. De quantas maneiras distintas você pode alcançar o topo?

Exemplo 1:
Entrada: n = 2
Saída: 2
Existem duas maneiras: (1 + 1) ou (2).
Exemplo 2:
Entrada: n = 3
Saída: 3
Existem três maneiras: (1 + 1 + 1), (1 + 2) ou (2 + 1).
