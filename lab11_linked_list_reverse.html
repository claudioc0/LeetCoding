Teoria & Fundamentos

Módulo 1: O Que São Listas Encadeadas e Como Funcionam Ponteiros

Pendente
Uma Lista Encadeada Simples (Singly Linked List) não armazena elementos contíguos na memória como um array. Em vez disso, cada elemento é um objeto independente chamado ListNode contendo:
1. val: O dado armazenado.
2. next: Uma referência (ponteiro) para o próximo nó da memória (ou None no final).

Para inverter a lista mantendo memória O(1), usamos 3 ponteiros:
  • prev: Nó anterior invertido (começa em None).
  • curr: Nó atual em processamento (começa em head).
  • next_node: Salva temporariamente curr.next antes de inverter a seta!

📊 Tabela de Rastreamento Passo a Passo

Etapa Estado dos Ponteiros / Dados Explicação Operacional
Início None prev = None; curr = head (nó 1)
Passo 1 [1] -> None curr.next = prev; prev = curr; curr = next_node
Passo 2 [2] -> [1] -> None curr.next = prev; prev = curr; curr = next_node
Passo 3 [3] -> [2] -> [1] -> None curr.next = prev; prev = curr; curr = next_node
Fim [4] -> [3] -> [2] -> [1] curr é None. Retornamos prev como nova cabeça!

Mini-Desafio 1: Contando Nós em uma Lista Encadeada

Crie a função contar_nos(head) que percorre a lista através de ponteiros next e retorna o número total de nós.

Pendente
Inicie com total = 0 e curr = head. Enquanto curr não for None, incremente o contador e avance curr = curr.next.
Prática Guiada 2

Mini-Desafio 2: Inserir Nó na Cabeça da Lista em O(1)

Crie a função inserir_inicio(head, val). Crie um novo nó com valor val, aponte seu next para head e retorne o novo nó como a nova cabeça!

Pendente
Crie o nó: novo = ListNode(val). Aponte para o antigo head: novo.next = head. Retorne novo.

LeetCode #206 Easy

Reverse Linked List

Não Resolvido
Dado o head de uma lista simplesmente encadeada, inverta a lista e retorne a nova cabeça invertida.

Exemplo 1: head = [1,2,3,4,5] -> [5,4,3,2,1]
Exemplo 2: head = [1,2] -> [2,1]
Exemplo 3: head = [] -> []
Dica: Mantenha três ponteiros: prev = None, curr = head. Em cada iteração, guarde next_node = curr.next, aponte curr.next = prev, e avance prev = curr e curr = next_node. Retorne prev.
