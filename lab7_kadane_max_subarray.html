Somas Acumuladas (Prefix Sum)

Como carregar uma mochila somando valores passo a passo.

Pendente (+50 XP)

🎒 A Mochila Acumuladora

Quando percorremos uma lista somando cada elemento a uma variável soma_atual, construímos a soma acumulada. Números positivos deixam a mochila mais rica; números negativos tiram valor dela.

soma_atual = 0
historico = []
for n in nums:
    soma_atual += n
    historico.append(soma_atual)

✂️ Fatiando a Partir do Segundo Item: nums[1:]

Quando inicializamos nosso estado com o primeiro elemento (soma_atual = nums[0]), podemos percorrer apenas os elementos seguintes usando o slice for n in nums[1:]:!

🧩 Mini-Desafio 1: Rastreando a Soma Acumulada

Crie a função somas_acumuladas(nums) que recebe uma lista de números e retorna uma lista com a soma acumulada passo a passo.

Dica: Inicie soma = 0 e res = []. Dentro do for n in nums:, faça soma += n e res.append(soma).
📖 Como resolver passo a passo:
  1. Crie soma = 0 e res = [].
  2. Para cada número n em nums, some soma += n.
  3. Guarde o valor atual com res.append(soma) e retorne res no final.

A Regra de Ouro de Kadane: Continuar ou Recomeçar?

Por que carregar uma soma acumulada negativa só atrapalha o futuro.

Pendente (+50 XP)

💡 O Insight Genial de Jay Kadane

Imagine que sua mochila anterior está com saldo negativo (soma_atual = -3) e você encontra o número n = 4 hoje. O que é melhor?

  • Continuar com a mochila velha: -3 + 4 = 1
  • Jogar a mochila negativa fora e recomeçar do número de hoje: 4!
# Em uma única linha com max():
soma_atual = max(n, soma_atual + n)

🧠 Resumo Mental

Se soma_atual antes de hoje era negativa, soma_atual + n será menor que n sozinho. Portanto, max(n, soma_atual + n) descarta automaticamente qualquer passado que dê prejuízo!

🧩 Mini-Desafio 2: A Escolha de Kadane em Cada Passo

Crie a função decisao_kadane(soma_anterior, numero_hoje) que retorna o maior valor entre continuar somando (soma_anterior + numero_hoje) ou recomeçar do zero a partir de numero_hoje.

Dica: Basta retornar max(numero_hoje, soma_anterior + numero_hoje)!
📖 Como resolver passo a passo:
  1. Compare o valor de recomeçar (numero_hoje) com o valor de continuar a sequência (soma_anterior + numero_hoje).
  2. Retorne o maior dos dois usando return max(numero_hoje, soma_anterior + numero_hoje).

Histórico das Melhores Somas Locais

Aplicando a decisão de Kadane para cada posição da lista.

Pendente (+50 XP)

📈 Melhor Subarray Terminando no Índice i

Se aplicarmos soma_atual = max(n, soma_atual + n) para cada elemento de nums[1:], teremos em cada passo a maior soma possível de uma fatia que termina exatamente naquele índice!

soma_atual = nums[0]
melhores_locais = [soma_atual]
for n in nums[1:]:
    soma_atual = max(n, soma_atual + n)
    melhores_locais.append(soma_atual)

🏆 Do Melhor Local para o Recorde Global

O maior número que aparecer em soma_atual durante todo o percurso será a resposta do Maximum Subarray!

🧩 Mini-Desafio 3: Rastreando as Somas de Kadane

Crie a função historico_kadane(nums) que retorna a lista contendo o valor de soma_atual em cada posição (começando com nums[0] e aplicando a regra de Kadane para nums[1:]).

Dica: Inicie soma_atual = nums[0] e historico = [soma_atual]. Depois faça for n in nums[1:]: atualizando soma_atual = max(n, soma_atual + n) e dando historico.append(soma_atual).
📖 Como resolver passo a passo:
  1. Defina soma_atual = nums[0] e historico = [soma_atual].
  2. Percorra do segundo item em diante com for n in nums[1:]:.
  3. Atualize soma_atual = max(n, soma_atual + n) e adicione em historico.append(soma_atual).
  4. Retorne historico.

🏆 LeetCode #53 — Maximum Subarray

⏳ Aguardando Submissão

Dado um array de inteiros nums, encontre o subarray contíguo (contendo pelo menos um número) que possui a maior soma e retorne essa soma.

Exemplo 1:
Entrada: nums = [-2,1,-3,4,-1,2,1,-5,4]
Saída: 6
O subarray [4,-1,2,1] tem a maior soma = 6.
Exemplo 2:
Entrada: nums = [5,4,-1,7,8]
Saída: 23
O subarray [5,4,-1,7,8] inteiro soma 23.
