Módulo 1

Strings em Python & Métodos de Limpeza

Strings em Python são imutáveis. Para manipulá-las, utilizamos métodos que retornam novas strings ou verificam caracteres.

Pendente

🔍 Inspeção de Caracteres: .isalnum()

Verifica se um caractere é alfanumérico (letra ou número), ignorando pontuações, traços e espaços:

"A".isalnum()    # True
"3".isalnum()    # True
",".isalnum()    # False (vírgula)
" ".isalnum()    # False (espaço)

🔡 Normalização: .lower() e .upper()

Essencial em algoritmos para desconsiderar diferenças entre maiúsculas e minúsculas (case-insensitivity):

texto = "Panama"
print(texto.lower()) # "panama"
print(texto.upper()) # "PANAMA"

Módulo 2

O Superpoder do Fatiamento (Slicing) & [::-1]

Em Python, fatiar sequências é nativo, expressivo e extremamente rápido.

Pendente

✂️ Anatomia do Slicing: [start:stop:step]

  • s[0:3]: Pega do índice 0 ao 2 (o stop não é incluído).
  • s[::2]: Pula de 2 em 2 caracteres.
  • s[::-1]: Passo negativo (-1) inverte a string inteira de trás para frente!

⚡ Inversão Instantânea 

palavra = "radar"
invertida = palavra[::-1]
print(invertida) # "radar"

# É palíndromo?
print(palavra == invertida) # True!

Módulo 3

List Comprehensions & "".join()

Em vez de criar um loop com 4 linhas e `.append()`, o Python permite transformar e filtrar dados em uma única expressão elegante.

Pendente

🐌 Loop Tradicional com .append() 

chars = []
for c in "A-1!":
    if c.isalnum():
        chars.append(c.lower())
# chars = ['a', '1']

✨ List Comprehension (Pythonico) 

chars = [c.lower() for c in "A-1!" if c.isalnum()]
# Unindo tudo em uma string:
texto = "".join(chars) # "a1"

Módulo 4

A Técnica dos Dois Ponteiros (Two Pointers)

Por que criar novas strings quando você pode inspecionar a sequência original com ponteiros sem gastar memória extra?

Pendente
Comparação de Complexidade: Slicing vs Dois Ponteiros
Abordagem com Slicing s[::-1]

Tempo: O(n) | Memória: O(n) (cria uma cópia da string invertida na memória RAM).

Abordagem Two Pointers (In-Place)

Tempo: O(n) | Memória: O(1) Extra (apenas dois números inteiros `left` e `right`).

Desafio Prático: Valid Palindrome (Palíndromo Válido)

Aplique manipulação de strings, métodos de limpeza e Two Pointers para validar se uma frase é um palíndromo.

Não Resolvido

Enunciado: Uma frase é um palíndromo se, após converter todas as letras maiúsculas em minúsculas e remover todos os caracteres não-alfanuméricos, ela for lida da mesma forma para frente e para trás.

Dada uma string s, retorne True se for um palíndromo, ou False caso contrário.

  • Caracteres alfanuméricos incluem letras do alfabeto e números (c.isalnum()).
  • Ignore espaços, vírgulas, pontos e símbolos especiais.
  • Uma string vazia ou que contenha apenas símbolos não-alfanuméricos é considerada um palíndromo válido (True).
Exemplo 1:
s = "A man, a plan, a canal: Panama"
Saída: True
"amanaplanacanalpanama" é palíndromo
Exemplo 2:
s = "race a car"
Saída: False
"raceacar" não é igual a "racaecar"
Exemplo 3 (Edge Case):
s = " " (espaço em branco)
Saída: True
String vazia após filtrar é palíndromo
