Módulo 1

O que é uma Pilha (Stack) & Semântica LIFO

Uma pilha segue o princípio LIFO (Last-In, First-Out): o último elemento a entrar é obrigatoriamente o primeiro a sair.

Pendente

🍽️ O Modelo Mental: A Pilha de Pratos

Imagine que você está lavando pratos e empilhando um sobre o outro:

1 Você coloca o Prato A na mesa (base da pilha).
2 Você coloca o Prato B em cima do A.
3 Você coloca o Prato C em cima do B (novo topo).
👉 Se alguém for pegar um prato, qual ele pega primeiro? O Prato C! O último que entrou é o primeiro que sai.

Na computação, usamos pilhas para tudo que exige "desfazer" ou "voltar": botão Ctrl+Z, histórico do navegador, e validação de parênteses!

🐍 As 4 Operações de Pilha em Python

Em Python, não precisamos importar nenhuma biblioteca especial. Usamos uma lista comum stack = []:

Operação Em Python O que faz? Custo
Push (Empilhar) stack.append(x) Adiciona no topo O(1)
Pop (Desempilhar) x = stack.pop() Remove e retorna o topo O(1)
Peek (Olhar Topo) topo = stack[-1] Lê o topo sem remover O(1)
Is Empty? not stack True se vazia, False se cheia O(1)
⚠️ Atenção ao Desempenho: Nunca use stack.pop(0) para pilhas! Remover do início (índice 0) força o Python a deslocar todos os outros $n$ elementos da lista para a esquerda, custando tempo O(n). Remover do final com stack.pop() é imediato O(1)!

✏️ Mini-Desafio 1: Histórico do Navegador (Botão "Voltar")

Veja como o seu próprio navegador web usa pilhas para voltar páginas!

LIFO na Prática

O que o problema pede: Implemente a função historico(acoes). Você recebe uma lista de comandos em texto:
• Se a ação for "ACESSAR: <site>" $ o$ empilhe o nome do site.
• Se a ação for "VOLTAR" $ o$ desempilhe a página anterior (se a pilha tiver páginas!).
• Ao final de todas as ações, retorne a URL do site atual (o topo da pilha) ou "VAZIO" se não houver nenhuma página na pilha.

📊 Tabela de Rastreamento (Trace Table) do Exemplo 1:
Passo Comando Recebido Pilha ANTES Operação Feita Pilha DEPOIS Topo Atual
1 "ACESSAR: google.com" [] stack.append('google.com') ['google.com'] 'google.com'
2 "ACESSAR: leetcode.com" ['google.com'] stack.append('leetcode.com') ['google.com', 'leetcode.com'] 'leetcode.com'
3 "VOLTAR" ['google.com', 'leetcode.com'] stack.pop() ['google.com'] 'google.com' (Retorno!)
Dica: Inicie com stack = []. Para extrair a URL de "ACESSAR: site", use acao.replace("ACESSAR: ", "") ou acao.split(": ")[1]. Quando a ação for "VOLTAR", verifique primeiro if stack: antes de chamar stack.pop() para evitar erro de pilha vazia!

🔍 Como Raciocinar para Resolver este Desafio (Linha por Linha)

  1. Criamos a lista vazia: stack = []. Essa lista será a nossa pilha de histórico.
  2. Percorremos cada comando: for acao in acoes:.
  3. Identificamos o comando de acesso: se acao.startswith("ACESSAR: "), pegamos apenas o nome do site e fazemos stack.append(site). O novo site foi parar no topo!
  4. Identificamos o comando de voltar: se acao == "VOLTAR", precisamos remover a página atual. Atenção ao caso de borda: se a pilha já estiver vazia, não podemos fazer pop() senão o Python travaria com IndexError! Por isso escrevemos if stack: stack.pop().
  5. Retornando o resultado: se houver algo na pilha (if stack:), a página atual é a do topo: return stack[-1]. Se a pilha estiver vazia, retornamos "VAZIO".
Módulo 2

Mapeamento de Pares & O Enigma da Contagem

Por que contadores simples falham e como tabelas hash associam fechamento $ o$ abertura em tempo $O(1)$.

Pendente
🤔 O Grande Enigma: "Por que não posso apenas CONTAR os parênteses?"

Quase todo iniciante pensa: "Basta somar +1 quando abrir '(' e subtrair -1 quando fechar ')'! Se der 0 no final, está certo!"

Para apenas um tipo de parêntese isso até funciona, mas veja o que acontece com múltiplos tipos, como na string "([)]":

❌ Com Contador (Falha!):
1. Lê '(' $ o$ abertos = 1
2. Lê '[' $ o$ abertos = 2
3. Lê ')' $ o$ fechados = 1
4. Lê ']' $ o$ fechados = 2
Total: 2 abertos e 2 fechados. O contador diria: "VÁLIDO!" (Errado!)
✅ Com Pilha (Sucesso!):
1. Empilha '(' $ o$ stack = ['(']
2. Empilha '[' $ o$ stack = ['(', '['] (Topo é '[')
3. Chega ')' $ o$ Topo é '[', não '('! ERRO!
A Pilha sabe que o '[' abriu por último e TINHA que fechar primeiro!
💡 Moral da história: Contadores guardam apenas a quantidade. A Pilha guarda a ordem cronológica exata dos acontecimentos!

🗺️ Por que Mapear Fechamento $ o$ Abertura?

Criamos o dicionário com os caracteres de fechamento como chave e suas aberturas como valor:

# Chave = Fechamento | Valor = Abertura esperada:
pares = {
')': '(', # ')' espera '(' no topo
'}': '{', # '}' espera '{' no topo
']': '[' # ']' espera '[' no topo
}

⚡ Como o Código Usa esse Dicionário

Ao ler cada caractere char da string:

if char in pares:
# 1. É de fechamento! O par esperado é:
esperado = pares[char]
# 2. O topo da pilha precisa ser igual a 'esperado'!
else:
# É de abertura: guarda na pilha!
stack.append(char)

✏️ Mini-Desafio 2: Validador de Parênteses Simples

Trabalhando apenas com os caracteres '(' e ')'

Básico

O que fazer: Crie a função valida_parenteses_simples(s). Ela recebe uma string contendo apenas '(' e ')'. Retorne True se todos estiverem corretamente abertos e fechados, ou False se houver qualquer erro.

📊 Casos de Teste Rastreados:
Caso 1: "()" $ o$ True
1. '(' $ o$ empilha: ['(']
2. ')' $ o$ desempilha: []
Pilha vazia no fim $ o$ True!
Caso 2: ")(" $ o$ False
1. ')' $ o$ pilha vazia!
Tentou fechar sem abrir $ o$ False!
Caso 3: "(()" $ o$ False
1. '(' $ o$ ['(']
2. '(' $ o$ ['(', '(']
3. ')' $ o$ ['(']
Sobrou '(' na pilha $ o$ False!
Dica: Para cada caractere da string: se for '(', faça stack.append(char). Se for ')': se a pilha estiver vazia (not stack), significa que apareceu um fechamento sem ninguém antes, então retorne False na hora! Se não estiver vazia, faça stack.pop(). Ao sair do loop, retorne len(stack) == 0.

🔍 Como Raciocinar para Resolver este Desafio (Linha por Linha)

  1. Criamos a pilha vazia: stack = [].
  2. Loop por cada caractere: for char in s:.
  3. Se for abertura '(': empilhamos stack.append(char).
  4. Se for fechamento ')':
    • Primeiro checamos: a pilha está vazia? Se sim (if not stack: return False), tentamos fechar algo que nunca abriu!
    • Se não estiver vazia: desempilhamos o par que acabou de ser fechado com stack.pop().
  5. A checagem de ouro no final: return len(stack) == 0. Por que não simplesmente return True? Porque se a string for "(()", o loop termina e sobra um parêntese na pilha! Se sobrar algo, a expressão é inválida.
Módulo 3

Casos de Borda & O "Curto-Circuito" do Python

Em entrevistas de código, a maioria dos candidatos reprova nos casos de borda. Conheça as 4 armadilhas clássicas e como se proteger.

Pendente
⚠️ 1. Fechar Vazio

Ex: ")" ou ")("

Chega um fechamento, mas não há nenhuma abertura na pilha para fechar. Retorne False na hora.

⚠️ 2. Sobra no Final

Ex: "(()" ou "["

A string acaba mas a pilha ainda tem abertura pendente sem par. Retorne False.

⚠️ 3. Tipos Opostos

Ex: "(]"

O fechamento ] não combina com a abertura ( que estava no topo. Retorne False.

⚠️ 4. Ordem Cruzada

Ex: "([)]"

O colchete [ abriu por último, logo ele devia fechar antes do parêntese. Retorne False.

🛡️ A Proteção Contra Falhas: Curto-Circuito com if stack and stack[-1] == ...

Veja por que esta linha em Python é tão genial e segura:

if stack and stack[-1] == esperado:

Em Python, o operador and avalia da esquerda para a direita. Se a pilha estiver vazia, stack é avaliado como False e o Python nem tenta ler stack[-1]! Se tentasse ler stack[-1] com a pilha vazia, o programa travaria com erro fatal IndexError: list index out of range!

✏️ Mini-Desafio 3: Diagnóstico Preciso de Erros

Retorne o diagnóstico exato do que aconteceu com a expressão

Diagnóstico

O que fazer: Crie a função diagnosticar(s). Usando uma pilha, retorne uma das 3 mensagens exatas:
• "OK": Se todos os parênteses estiverem perfeitamente balanceados.
• "FECHOU_SEM_ABERTURA": Se tentar fechar um ')' quando a pilha já estiver vazia.
• "ABERTURA_PENDENTE": Se o loop terminar e ainda sobrar alguma abertura na pilha.

Raciocínio dos 3 Retornos:
1. Sucesso ("(())"): Abre 2x, fecha 2x. Pilha esvaziou $ o$ retorne "OK".
2. Erro Precoce ("())"): No 3º caractere ')', a pilha já está vazia $ o$ retorne "FECHOU_SEM_ABERTURA".
3. Erro Tardio ("((()"): Fim da string, mas sobrou um '(' na pilha $ o$ retorne "ABERTURA_PENDENTE".
Dica: Em cada ')', confira primeiro: if not stack: return "FECHOU_SEM_ABERTURA". Se não estiver vazia, faça stack.pop(). Após o loop terminar, confira: if stack: return "ABERTURA_PENDENTE". Se passar pelos dois, retorne "OK"!

🔍 Como Raciocinar para Resolver este Desafio (Linha por Linha)

  1. Inicie a pilha vazia: stack = [].
  2. Percorra a string: for char in s:.
  3. Para cada '(': adicione com stack.append(char).
  4. Para cada ')': teste imediatamente se a pilha está vazia (if not stack: return "FECHOU_SEM_ABERTURA"). Se não estiver, desempilhe com stack.pop().
  5. Depois do fim do loop: se a pilha ainda tiver elementos (if stack:), retorne "ABERTURA_PENDENTE". Caso contrário, todos os pares fecharam perfeitamente: retorne "OK"!

20. Valid Parentheses (Parênteses Válidos)

O problema clássico número 1 para dominar pilhas em entrevistas de Big Techs.

⏳ Pendente de Resolução

Dada uma string s contendo apenas os caracteres '(', ')', '{', '}', '[' e ']', determine se a string de entrada é válida.

As 3 Regras de Validade:
  1. Parênteses abertos devem ser fechados pelo mesmo tipo ((), [], {}).
  2. Parênteses abertos devem ser fechados na ordem correta (LIFO: o último que abriu fecha primeiro).
  3. Cada parêntese de fechamento tem que ter um parêntese de abertura correspondente.

📚 Guia Completo de Resolução Passo a Passo (A Estratégia de Big Techs)

Teoria Clara

Este problema é resolvido com um algoritmo elegante de 3 Etapas:

Etapa 1: Tamanho Ímpar O(1)

Se len(s) % 2 != 0, é impossível formar pares completos! Podemos retornar False imediatamente sem nem olhar a string.

Etapa 2: Pilha + Dicionário O(n)

Percorremos a string. Se o caractere for de fechamento, olhamos se o topo bate com a abertura esperada. Se bater, removemos (pop). Se for de abertura, empilhamos.

Etapa 3: Pilha Vazia no Final

Ao terminar a string, a expressão é válida se e somente se a pilha estiver vazia (return not stack). Se sobrou algo, faltou fechar!

📊 Rastreamento Completo de Exemplo Válido: s = "{[()]}"
Passo Char Tipo Pilha Antes Decisão / Operação Pilha Depois Status
1 '{' Abertura [] Empilha: stack.append('{') ['{'] Ok
2 '[' Abertura ['{'] Empilha: stack.append('[') ['{', '['] Ok
3 '(' Abertura ['{', '['] Empilha: stack.append('(') ['{', '[', '('] Ok (Topo é '(')
4 ')' Fechamento ['{', '[', '('] Topo é '('? Sim! stack.pop() ['{', '['] Match '(' e ')'!
5 ']' Fechamento ['{', '['] Topo é '['? Sim! stack.pop() ['{'] Match '[' e ']'!
6 '}' Fechamento ['{'] Topo é '{'? Sim! stack.pop() [] Match '{' e '}'!

✅ Fim da String: A pilha terminou com 0 elementos (len(stack) == 0), logo a função retorna True!

📊 Rastreamento Completo de Exemplo Inválido: s = "([)]"
Passo Char Tipo Pilha Antes Decisão / Operação Resultado Imediato
1 '(' Abertura [] Empilha '(' $ o$ stack = ['('] Ok
2 '[' Abertura ['('] Empilha '[' $ o$ stack = ['(', '['] Ok (Topo é '[')
3 ')' Fechamento ['(', '['] ')' espera '(' mas o topo é '['! Descasou! Retorna False imediatamente!
🔍 Anatomia da Solução Linha por Linha:
Linha de Código em Python O que ela faz em português simples?
if len(s) % 2 != 0: return False Se o total for ímpar, é impossível fechar todos os pares. Corta o caminho logo de cara.
stack = [] Cria a pilha vazia para armazenar as aberturas que ainda não foram fechadas.
pares = {')': '(', '}': '{', ']': '['} Mapeia cada fechamento para a respectiva abertura que deve estar no topo da pilha.
for char in s: Percorre a string caractere por caractere, da esquerda para a direita.
if char in pares: Testa se o caractere atual é de fechamento (isto é, uma chave do dicionário).
if stack and stack[-1] == pares[char]: Confere se a pilha NÃO está vazia E se o topo é o par exato esperado.
stack.pop() Se for o par exato, remove a abertura do topo (par fechado com sucesso!).
else: return False Se a pilha estiver vazia ou o topo não bater, a string é inválida na hora.
else: stack.append(char) Se o caractere for de abertura ('(', '{', '['), apenas empilha no topo.
return not stack Se a pilha esvaziou totalmente, retorna True. Se sobrou alguma abertura, False.
Dica 1: Crie um mapa de fechamento para abertura: pares = {')': '(', '}': '{', ']': '['} e uma lista stack = []. Se o caractere for uma chave de pares, significa que é um caractere de fechamento!
Dica 2: Quando encontrar um caractere de fechamento, confira se a pilha NÃO está vazia e se o topo bate com a abertura esperada: 
if stack and stack[-1] == pares[char]:
    stack.pop()
else:
    return False
Se não for fechamento, empilhe: stack.append(char). Ao final de tudo, retorne not stack.

📊 Análise de Complexidade de Algoritmo (Big-O)

Complexidade de Tempo: O(n) Iteramos pelos caracteres da string exatamente uma vez. Cada operação de append e pop na lista de Python leva tempo $O(1)$ amortizado.
Complexidade de Espaço: O(n) No pior caso (ex: string com apenas caracteres de abertura "((((("), todos os $n$ elementos serão armazenados na pilha.
