A Lei do Gargalo: Calculando a Área de Água

Por que a água é limitada pela menor das duas paredes e pela distância entre os índices.

Pendente (+50 XP)

🌊 Largura × Altura Útil

Se escolhermos duas colunas nos índices esq e dir:

  • A largura da base é a distância entre os índices: largura = dir - esq.
  • A altura da água é limitada pela parede mais baixa (senão a água transborda!): altura = min(alturas[esq], alturas[dir]).
largura = dir - esq
altura_util = min(alturas[esq], alturas[dir])
area = largura * altura_util

📐 Exemplo Prático

Se esq = 1 (altura 8) e dir = 8 (altura 7), a largura é 8 - 1 = 7 e a altura útil é min(8, 7) = 7. Área = 7 * 7 = 49!

🧩 Mini-Desafio 1: Calculadora de Volume do Tanque

Crie a função calcular_area(alturas, esq, dir) que retorna a quantidade de água armazenada entre as paredes dos índices esq e dir.

Dica: Calcule largura = dir - esq e altura = min(alturas[esq], alturas[dir]), depois retorne largura * altura.
📖 Como resolver passo a passo:
  1. Subtraia os índices para achar a base: largura = dir - esq.
  2. Use min(alturas[esq], alturas[dir]) para achar o nível máximo da água.
  3. Retorne o produto largura * altura.

Qual Ponteiro Mover? Eliminando o Gargalo

Por que devemos sempre mover o ponteiro da parede mais baixa.

Pendente (+50 XP)

🧠 A Lógica dos Dois Ponteiros

Começamos com a maior largura possível (esq = 0 e dir = len(alturas) - 1). A cada passo, a largura vai diminuir em 1. A única chance de conseguir uma área maior é encontrar uma parede mais alta no lugar da parede que hoje é o gargalo (a menor)!

if alturas[esq] < alturas[dir]:
    esq += 1    # Parede esquerda era o gargalo; avançamos esq!
else:
    dir -= 1    # Parede direita era menor ou igual; recuamos dir!

❌ E se movermos a parede mais alta?

Se mantivermos a parede baixa parada e movermos a alta, a largura diminui e a altura continua presa no limite da parede baixa — ou seja, a área jamais poderia aumentar!

🧩 Mini-Desafio 2: Decisor de Movimento dos Ponteiros

Crie a função proximos_ponteiros(alturas, esq, dir) que verifica qual das duas paredes (alturas[esq] ou alturas[dir]) é menor e retorna a nova posição [esq + 1, dir] se a esquerda for menor, ou [esq, dir - 1] caso contrário.

Dica: Use if alturas[esq] < alturas[dir]: return [esq + 1, dir] e no else: return [esq, dir - 1].
📖 Como resolver passo a passo:
  1. Compare if alturas[esq] < alturas[dir]:.
  2. Se verdadeiro, a parede esquerda é o gargalo, então avançamos o ponteiro esquerdo: return [esq + 1, dir].
  3. No else:, recuamos o ponteiro direito: return [esq, dir - 1].

Rastreando o Recorde de Água durante a Convergência

Combinando o cálculo de área com o movimento dos ponteiros no loop while esq < dir.

Pendente (+50 XP)

🔄 O Ciclo Completo de Convergência

Enquanto esq < dir, calculamos a área atual, atualizamos o recorde maior_agua e movemos o ponteiro da menor parede:

while esq < dir:
    area = (dir - esq) * min(alturas[esq], alturas[dir])
    maior_agua = max(maior_agua, area)
    if alturas[esq] < alturas[dir]:
        esq += 1
    else:
        dir -= 1

⚡ De O(n²) para O(n)

Em vez de testar todos os pares possíveis de paredes com dois loops aninhados, fazemos apenas uma caminhada das bordas até o centro!

🧩 Mini-Desafio 3: Histórico de Áreas Testadas

Crie a função areas_convergentes(alturas) que executa o algoritmo dos dois ponteiros (esq = 0, dir = len(alturas) - 1) e retorna uma lista com todas as áreas calculadas passo a passo até que esq == dir.

Dica: Crie historico = [], esq = 0 e dir = len(alturas) - 1. No while esq < dir:, calcule area, dê historico.append(area) e mova o menor ponteiro.
📖 Como resolver passo a passo:
  1. Inicialize esq = 0, dir = len(alturas) - 1 e historico = [].
  2. Enquanto esq < dir, calcule area = (dir - esq) * min(alturas[esq], alturas[dir]) e adicione em historico.append(area).
  3. Mova esq += 1 se alturas[esq] < alturas[dir], senão dir -= 1.
  4. Retorne historico.

🏆 LeetCode #11 — Container With Most Water

⏳ Aguardando Submissão

Você recebe um array de inteiros height de tamanho n. Existem n linhas verticais desenhadas. Encontre duas linhas que, junto com o eixo x, formem um recipiente que contenha a maior quantidade de água e retorne a área máxima.

Exemplo 1:
Entrada: height = [1,8,6,2,5,4,8,3,7]
Saída: 49
As paredes nos índices 1 (altura 8) e 8 (altura 7) têm distância 7 e altura útil min(8,7)=7 -> 7 * 7 = 49.
Exemplo 2:
Entrada: height = [1,1]
Saída: 1
Distância 1 * altura 1 = 1.
